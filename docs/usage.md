# YetToTell · 讲未 使用说明

本地运行的 Markdown 授课工具。课程内容、图片布局和互动控件均可随仓库迁移，不需要云端账户。默认作者、联系方式与 PDF 签名为空。

## 启动与生成

- 双击 `更新课件.cmd`，从 `课程.md` 生成网页；或运行 `python lesson/build_markdown.py`。
- 双击 `启动课件.cmd`，打开本地服务。网页中“编辑 → 保存到 MD”会更新课程文件，并重新生成网页。
- 双击 `课件.html` 可离线放映。离线模式的“保存到 MD”会下载新的 `课程.md`；将其替换回课程目录，再运行生成命令。浏览器不会静默覆盖任意本机文件。
- `更新PDF.cmd` 生成匿名学生版和教师版 PDF。使用网页导出可应用“设置”中的签名。

重新生成网页只需 Python 3.10+。PDF 导出、自动验收需要 Microsoft Edge 和以下 Python 依赖。建议在框架目录创建环境，启动器会优先使用它。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

结束授课后，双击根目录的 `结束服务.cmd`。脚本会核对服务所属目录，再请求正常退出并清理 PID；不会按进程名称批量结束 Python。关闭标签页不会关闭服务。

默认端口 18801。多门课程并行运行可先设置 `$env:CLASSROOM_PORT = '18802'`，再运行 `lesson/start.ps1`。启动器核验服务版本和所属目录；发现另一个课程或旧服务时会停止启动，不会自动结束未知进程。

## 放映和菜单

右上角包含目录、编辑、设置、菜单与全屏。演示者视图、PDF 导出与计时器位于菜单内。

- 空格 / 右箭头展开下一项；底部箭头直接翻页；R 展开当前页。
- J 打开演示者视图；教师窗口可以选页并控制学生页面。
- G 打开目录，F 进入或退出全屏，Ctrl+Shift+E 切换编辑。
- 全屏时其他工具淡出并停止接收点击和焦点，仅保留翻页、逐步展开、目录和退出全屏。退出后恢复。

共享屏幕时只共享学生窗口。学生 PDF 不含逐字稿与教师答案。HTML 内含完整备课数据，分发给学生请用学生 PDF。

## Markdown 内容

`课程.md` 是唯一公开内容源。作者和邮箱可留空；若手动填写，会进入课程源文件。PDF 个性签名请在网页“设置”中填写，不要填写到公开课程文件。

每页以 `## 页标题 {#unique-id}` 开始，编号需唯一，只用小写字母、数字和连字符。填写 `章节`、`时长`、`路径` 和 `动画`。普通页面的动画留空，路径为“主线”或“补充”。

| 小标题 | 内容 |
| --- | --- |
| `### 页面` | 每行一个 `- 要点`，支持加粗、行内代码、图片与公式 |
| `### SQL` | 可选代码块，只展示，不执行 |
| `### 问题` | 可选课堂提问 |
| `### 教师答案` | 有问题时必填，仅教师页面和教师 PDF 显示 |
| `### 逐字稿` | 必填教师讲稿 |
| `### 备课提示` | 可选操作和节奏提示 |

支持明确结构的 Markdown 子集，不支持任意正文 HTML、嵌套列表或复杂表格。行内公式写 `$E=mc^2$`，独立公式写 `$$...$$`；KaTeX 文件和许可证保留在 `assets/katex`。

## 插入和编辑图片

进入编辑模式后，可以填写 `https://图床地址/image.png` 或 `assets/image.png`，也可以“选择本机图片”。支持 PNG、JPEG、WebP、GIF、SVG。

本地服务模式会把选择的图片复制到 `assets/uploads`，使用内容摘要命名，不保存原电脑绝对路径。离线模式会将选择的图片以内嵌 data URL 放入下载的 Markdown。单次上传不超过 8 MB，建议使用压缩后的图片。普通 Markdown 图片仍支持 `- ![说明](assets/example.svg)`；编辑模式点击它，会转换为可移动控件，源要点仍保留。

图片网址直接由浏览器加载，不上传到任何图床。外链需要网络，并受图床防盗链和跨站限制影响；要保证离线可用，请下载到课程资源目录后引用。PDF 导出会检查图片是否加载成功，失败时会报错，避免无声导出空图。

点击图片或控件选择，拖动移动，拖动右下角缩放；侧栏也可输入位置与尺寸。右键图片可切换“在每页固定显示”，也可勾选侧栏的对应选项。固定图片在各学生课件页和学生画面 PDF 中重复显示，教师逐字稿页不重复放置。固定仍可编辑，适合 logo。

布局保存为页面的百分比坐标；原点为页面左上角，宽高基准为整张幻灯片。屏幕与 PDF 均采用 16:9 画布。内容较多或字体调大后，请检查是否超出控件边界。

## 可保存的字体与布局

进入编辑模式，点击页面标题、某条正文、课堂问题或独立文字框，即可在同一个侧栏修改文字。双击可将输入焦点移到内容框。输入会立即预览并保留在当前编辑草稿中，切换选中对象不需要再点“应用内容”；最后点击“保存到 MD”写入文件。

- **原文文字**：直接回写 Markdown 的对应标题、要点或问题，不额外生成覆盖文字。原有逐步展开和页面布局保持不变。正文换行使用 <br> 保存。原文可拖动移动，右下角可调整区域大小，默认位置及逐步展开顺序保持不变。
- **独立文字框**：保存在 `classroom` 的 `type: "text"` 控件中，可以自由拖动和缩放；支持换行、`**加粗**`、行内代码和 `$公式$`，与正文使用同一套基本格式。输入时自动增加高度；“适应文字高度”可以收紧多余空间。超出画布底部会提示上移、加宽或减小字号。

侧栏会明确标明“原文 · 第 N 条正文”或“独立文字框”。字体设置作用于当前选中的那一条；选择“整页正文样式”可设置全页默认样式，单条已设置的样式优先。标题、正文、问题和独立文字框均支持字号、字体类别、颜色、粗细和对齐。

“保存到 MD”只修改选中过的原文字段，并更新唯一的 `classroom` 代码块。未改动的正文、教师答案、讲稿及图片路径保持原样。保存前会校验控件、图片路径和格式，原 Markdown 备份存入 `.local/backups`。如果源文件在页面载入后发生变化，会拒绝覆盖；先下载当前改动留存，再刷新重新编辑。“撤销全部未保存”同时恢复最近一次保存的文字和布局。

```classroom
{
  "version": 1,
  "slides": {
    "intro": {
      "styles": {
        "title": {"fontSize": 36, "fontFamily": "sans", "color": "#172633", "bold": true, "align": "left"}
      },
      "elements": [
        {"id": "logo", "type": "image", "src": "assets/logo.svg", "alt": "课程标志", "x": 90, "y": 3, "w": 7, "h": 9, "fixed": true},
        {"id": "observation", "type": "widget", "widget": "counter", "x": 54, "y": 30, "w": 35, "h": 40, "props": {"label": "观察数值", "min": 0, "max": 100, "step": 5, "value": 20}}
      ]
    }
  }
}
```

`slides` 的键必须对应页标题的编号。控件 id 在整个课程内唯一。`x/y/w/h` 均为 0—100 的百分数，宽高至少为 2，控件不得超出画布。`fixed` 只适用于图片。`styles` 支持 `title`、`points`、`question`、`point-0` 等要点索引。`fontFamily` 支持 sans、serif、mono 和已安装的字体名称；本机字体文件不随发布包分发。自动转换的 Markdown 图片可能包含 `point` 索引，用来避免原图片与控件重复显示，不要随意改动。

## 互动控件格式

内置控件以 `type: "widget"` 指定，位置、尺寸和字体与图片共用规则。编辑时控件交互暂停，完成编辑后恢复。课堂中的点击和滑动状态不写回 Markdown；只有编辑侧栏修改的初始参数被保存。

| widget | props | PDF 静态内容 |
| --- | --- | --- |
| `counter` | `label/min/max/step/value` | 初始值、范围和步长 |
| `range` | `label/min/max/step/value` | 初始值、范围和步长 |
| `tabs` | `label/items`，items 是 `[{"label":"标签","text":"内容"}]` | 所有标签与内容 |
| `reveal` | `label/text` | 展开后的内容 |

`reveal` 是课堂互动展示，不是教师答案保密区。真正只给教师看的内容，请放在 `### 教师答案`。

普通文字使用 `type: "text"`、`text` 字段。自定义互动 HTML 使用固定接口：

```json
{"id":"color-demo","type":"html","src":"assets/widgets/color-demo.html","alt":"颜色演示","printText":"颜色切换演示的步骤和静态结论。","x":53,"y":27,"w":38,"h":47}
```

HTML 文件应自包含，CSS 和 JavaScript 写在文件内，图片使用 data URL。框架把它嵌入隔离 iframe，只允许脚本运行，不允许访问父页面、外部网络、表单提交或本机路径。控件区域会自动适应拖动后的尺寸；示例在 `assets/widgets/color-demo.html`。导出 PDF 使用必填的 `printText`，不尝试截图未知动画状态。

## PDF 签名

“设置”可填写署名、联系信息并启用隐藏署名。设置仅保存在当前浏览器的本地存储，按页面路径区分；不会写进 Markdown、网页源码或仓库配置。清空签名后可匿名导出。命令行导出默认匿名。

启用后，PDF 元数据、XMP 与逐页不可见文字包含署名、联系方式、导出编号和时间。支持中文署名与特殊字符；导出后校验元数据及每页标记，并比较插入标记前后的可见像素。此处的“签名”是追溯署名，不是证书数字签名，也不能阻止他人删除或截图。

可指定 `1-3,5` 等课件页码；教师版附对应页的讲稿。未保存的布局需要先保存后再导出。普通浏览器打印可以保留当前画面布局，但不保证加入隐藏署名。

## 文件与发布

- `课程.md`、`assets`：课程内容与媒体。
- `lesson/dist`：网页源码；其 `assets` 下同名 JS/CSS 是生成副本，KaTeX 是保留的本地依赖。
- `lesson/classroom.py`：控件格式、校验、媒体嵌入。
- `lesson/source_text.py`：原文字段定位与局部回写，保留未编辑的 Markdown。
- `lesson/build_markdown.py`、`package_v2.py`：构建与打包。
- `lesson/server.py`：本地保存、图片导入与 PDF 服务。
- `tests/test_workflow.py`：在隔离副本中运行浏览器和 PDF 回归，不修改正式课程。

运行验收：`python tests/test_schema.py`、`python tests/test_workflow.py`、`python tests/test_text_editing.py`。输出在 `tests/output`，被 Git 忽略。

旧迁移脚本和原课程历史副本已移到框架目录外的本机备份，不属于发布内容。`.gitignore` 排除本机环境、服务日志、PID、导出 PDF、备份、验收副本及生成产物。复制整个框架后先重新生成。发布自己的课程前自行检查媒体和讲稿是否适合公开；本框架不执行 GitHub 推送。

生成可上传的源码包：`python lesson/package_release.py`。压缩包位于课程目录外，只收集明确列出的源码和媒体，排除浏览器设置、本机环境、备份、日志、PDF 和验收输出。上传 GitHub 后先运行生成命令；不要直接提交本机工作目录的所有文件。
